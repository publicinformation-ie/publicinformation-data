## Future work (out of scope for this change)

Each item below is a candidate follow-up change; none blocks merging this one.

- **`audit.py` ignores `override.json`.** `audit_head` re-runs detection without overrides, so it reports emra, recreational-craft and gda as invalid although production (`validate_split` after `merge_overrides`) has zero `InvalidStructure`. Apply overrides in the audit, or label its output "raw detection".
- **Column-aware section boundaries.** Boundaries are one-dimensional `(page, y)` points, so two headings on the same baseline in different columns cannot both start a section. This change handles the seven known cases with `drop` + retitle overrides (emra, year-one, gda, moving-together, national-ports ×3, recreational-craft ×2); the merged section's text still interleaves both columns. A real fix needs `(page, column, y)` boundaries through `assemble_sections`.
- **Remaining junk numbering titles.** 6.13 removed the lowercase-start fragments; a few capitalised prose lines that begin with a number remain (e.g. national-cycle-network-plan `6.1 MtCO2eq by 2030, in line with…`). A sentence-shape test beyond `_looks_like_a_sentence` would catch them.
- **Long outline bookmarks are dropped.** `filter_outline` (and the `split_issues` gate) apply `MAX_TITLE_CHARS = 120` to author bookmarks, so climate-action-plan-2024 loses `7.3`, `7.4` and `7.6` (130+ char "Principle" titles; logged `OutlineEntryDropped`, text kept in the preceding section). `main` published them. Give outline-sourced titles a separate, larger cap in both places.
- **Climate Action Plan residuals.** climate-action-plan-2025 (23) and 2025-q2-q3 (16) carry `OutlineEntryUnresolved`; some progress-report TOC entries still miss (`4 Electricity`, `7 LULUCF` in 2025 Q4; `3 Transport` in 2025 Q1), so those sections are absorbed by their predecessor. climate-action-plan-2023 stays `hold`.
- **fishing-vessels nesting.** code-of-practice-fishing-vessels-under-15m now takes the TOC path (11 → 152 nodes, all real headings) but some levels nest oddly (`3.1.x` under `2.2`); review its TOC level inference.
- **`Chapter N` anchor (D4, deferred).** No document needs it to validate. emra (6 level-1 nodes) and gda (3) would gain a cleaner top level if `Chapter N` lines anchored level 1; do it as its own change with a corpus-wide blast-radius check.
- **17 residual `OutlineEntryUnresolved` in the original 24 documents.** gda ×2, tii ×7, national-ports ×1, national-roads-2040 ×1, recreational-craft ×6, plus the page+1 cases (InDesign `/Fit` bookmarks pointing a page late). page+1 search is deliberately absent because gda's chapter-18 bookmark points a page *early*; any page+1 fallback must stay fail-closed.
- **Minor:** `_find_title_line`'s page−1 fallback recomputes `body_size(pages)` per miss; hoist it if detect_structure gets slow.
- **Runner skips `fetch_pdfs` for new `documents.yml` entries.** `process.py` reported `fetch_pdfs` "up to date" after the Climate Action Plan entries were merged in; the step itself (run directly) fetches them. The runner's freshness check should include `documents.yml`.
