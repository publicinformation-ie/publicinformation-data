Disclosure Log

Section 48 of the Freedom of Information Act provides that the Minister may draw up and publish a Code of Practice for FOI. This code is available on the Central Policy Unit’s website.

This Code requires that FOI bodies would publish a disclosure log which displays details about the non personal requests which have been received by the body. The NTMA disclosure log is published each quarter and is displayed below.
